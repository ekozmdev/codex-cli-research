# codex-cli-research

Codex Web上でこのリポジトリを使い、codex-cliの仕組みや動作、最新バージョンの変化を調査してレポートにまとめるための作業用リポジトリです。

## 目的

- codex-cliの正式リリースを追跡し、重要な変更点をレポート化する。
- 調査の経緯・差分・補足メモを`reports/`に蓄積する。

## 使い方（Codex Web向け）

1. `README.md`と`reports/`から「前回調査したバージョン」を確認する。
2. 一時ディレクトリに`openai/codex`をcloneし、タグを取得する。
3. 新しい正式タグがあれば差分を確認してレポートを作成する。
4. レポートに合わせて`README.md`のバージョン情報を更新する。
5. 新しい正式タグが無ければ何も変更しない。

## レポート運用ルール（要約）

- プレリリース（alpha/beta/rcなど）は除外する。
- `rust-`などの接頭辞があっても、`x.y.z`形式の正式タグのみを対象とする。
- 有益な差分が無ければ「特筆事項なし」と明記する。
- 新しい正式版が無い場合、既存ファイルは更新しない。

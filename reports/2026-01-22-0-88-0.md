# codex

## 前回調査したバージョン

0.80.0 (tag: rust-v0.80.0)

## 今回調査したバージョン

0.88.0 (tag: rust-v0.88.0)

## 追加された機能・設定項目

- デフォルトAPIモデルが gpt-5.2-codex に更新された。
- `codex mcp-server` の `codex` ツールが `threadId` を返すようになり、`CallToolResult` でも `threadId` を `content` と `structuredContent` の両方で返すようになった。
- ヘッドレス環境でのデバイスコード認証フローが強化され、単独フォールバックとしても利用できるようになった。
- Linuxサンドボックスで読み取り専用マウントが利用可能になり、ユーザーネームスペースが使えない場合はLandlockのみで隔離するフォールバックが追加された。
- TUIで部分的なツールコール表示が可能になり、未購読スレッドの承認要求も表示できるようになった。
- ユーザーのシェルコマンドがユーザースナップショット下で実行され、シェル設定やエイリアスが反映されるようになった。
- コラボレーション機能が拡張され、アプリサーバーがコラボツール呼び出しをイベントとして配信し、`spawn_agent` のロール指定や `send_input` の割り込み送信、`wait` の複数ID待機に対応した。加えてコラボレーションモードの導入と開発者向け手順が追加された。
- Skillsで `SKILL.toml` によるメタデータ定義が可能になった。
- `/models` のメタデータにマイグレーション用のMarkdownが追加された。
- `config.toml` のJSON Schemaが追加され、設定ファイルの検証に利用できるようになった。
- Web検索を明示的に無効化できるヘッダーが追加された。

## 廃止された(または廃止予定の)機能・設定項目

- 特筆事項なし。

## その他

- `config.toml` を信頼済みディレクトリからのみ読み込むようになり、シンボリックリンクの解決も修正された。
- Azureエンドポイントの無効入力エラーやWSLのTUI画像ペースト回帰、コンパクション時のトークン見積もりなど複数の不具合が修正された。
- Rust 1.92への更新を含む依存関係の更新が実施された。
